- Supported consumers: .NET 11, .NET 10 and .NET Framework 4.8.1. .NET 5 through 9 are no longer shipped.
- The MSBuild task selects rtcli from the consumer's framework: net481, net10.0, net11.0; net12.0 and later use the net11.0 tool with major-version roll-forward; unsupported frameworks fail the build with a clear error.
- Fixes: Visual Studio (full-framework) MSBuild loading the task from a folder the package did not ship; .NET Framework consumers resolving a tools folder that did not exist; net11.0 consumers being treated as .NET Framework; RtBypassTypeScriptCompilation=true failing SDK-style builds.
- The package has no dependencies and no frameworkAssemblies; it now carries SourceLink, a symbols package and this README.
