- Generated files whose content is unchanged are no longer rewritten, so their timestamps survive and downstream TypeScript tooling is not invalidated.
- Check mode (RtCheckMode=true, rtcli CheckMode=true): generates in memory and fails with RTE0019 when the files on disk differ; nothing is written. For CI drift gates.
- System.Text.Json awareness (UseSystemTextJson, off by default): JsonPropertyName, JsonIgnore and its conditions, JsonPropertyOrder, JsonStringEnumConverter, JsonStringEnumMemberName, and JsonPolymorphic/JsonDerivedType as discriminated unions. Attributes are detected by full name; no new dependency. JsonNamingPolicy mirrors System.Text.Json's naming policies.
- Modern TypeScript output options, all off by default: UseTypeImports, EnumsAsUnionTypes, ReadonlyProperties, StrictNullability.
- Effect Schema emitter (RtEffectSchemaFile, rtcli EffectSchemaFile): writes an Effect 4 Schema module for the exported DTOs alongside the TypeScript output.
- Skip unchanged generations (RtSkipUnchanged=true, opt-in; RtForce=true regenerates): the task does not start rtcli when source assemblies, XML docs, references, settings, tool and current output are unchanged since the last successful run.
- Upstream fixes, always on: no MSB4057 when TypeScriptTarget is set without TypeScript targets (https://github.com/reinforced/Reinforced.Typings/issues/313, https://github.com/reinforced/Reinforced.Typings/issues/231); no RT0999 when the consumer references a System.Text.Json newer than the runtime (https://github.com/reinforced/Reinforced.Typings/issues/284, https://github.com/reinforced/Reinforced.Typings/issues/206); explicit interface implementations are not exported (https://github.com/reinforced/Reinforced.Typings/issues/250); ulong enum values above long.MaxValue are exported (https://github.com/reinforced/Reinforced.Typings/issues/221); "rtcli profile" without a path prints usage and exits 1 (https://github.com/reinforced/Reinforced.Typings/issues/226).
- BEHAVIOUR CHANGE: the default output now compiles under TypeScript 6 and 7 in strict mode. Namespaces are written "namespace X {" instead of "module X {", which TypeScript 6 and 7 reject with error TS1540 (https://github.com/reinforced/Reinforced.Typings/issues/286); opt out with UseNamespaceKeyword(false). Stub bodies of exported class methods are "return null!;" instead of "return null;" (TS2322 under strictNullChecks). Nothing else in the default output changes.
- Upstream fixes, opt-in: ConvertDocumentationTags turns see cref and other inline XML doc tags into JSDoc {@link} and text (https://github.com/reinforced/Reinforced.Typings/issues/310).
- With no other new option set, generated output differs from 3.0.0 only by the two changes above. CI type-checks the e2e golden files with TypeScript 6.0.2 and 7.0.2 (strict).
